# CLCOMX 0.6.0

릴리즈 성격: 기능 릴리즈

## 변경점

- Claude Code 세션의 화면 렌더링 방식을 터미널 설정에서 선택할 수 있게 했습니다.
  - `설정을 따름`: CLCOMX가 별도 환경 변수를 주입하지 않고 Claude 자체 설정에 맡깁니다.
  - `전체 터미널 화면`: 새 Claude 세션에 `CLAUDE_CODE_NO_FLICKER=1`을 주입해 깜빡임 없는 alt-screen 렌더러를 사용합니다.
  - `기본 출력`: 새 Claude 세션에 `CLAUDE_CODE_NO_FLICKER=0`을 주입해 인라인 출력 렌더러를 강제합니다.
- Claude 시작/복구 명령 조립 경로가 환경 변수 prefix를 지원하도록 확장됐습니다.
  - 값은 shell quote 처리하고, 환경 변수 이름은 shell assignment로 안전한 이름만 허용합니다.
  - 기존 `--enable-auto-mode` 옵션과 함께 사용할 수 있습니다.
- 설정 저장/복구 경로에 `claudeTui` 값을 추가했습니다.
  - Rust 설정 파서에서 `auto`, `fullscreen`, `default`만 허용하고 다른 값은 기본값 `auto`로 정규화합니다.
