# CLCOMX 0.5.5

릴리즈 성격: 패치 릴리즈

## 변경점

- 터미널 출력에서 줄바꿈으로 분리된 URL과 파일 경로 인식을 개선했습니다.
  - xterm 소프트 래핑뿐 아니라 프로그램 출력이 실제 개행으로 끊은 하드 줄바꿈도 완성된 링크로 인식합니다.
  - `.agent-works/...`처럼 여러 줄로 나뉜 상대 경로를 각 줄에서 같은 완성 경로로 열 수 있게 했습니다.
  - `https://claude` + `.ai`, `https:/` + `/example.com/docs`처럼 끊긴 URL도 완성된 URL로 처리합니다.
- 링크 range 계산을 xterm의 1-based buffer range 방식에 맞춰 보정했습니다.
- 완성된 URL이나 파일 경로 뒤의 일반 텍스트를 잘못 이어 붙이지 않도록 negative case를 보강했습니다.
