# CLCOMX 0.5.6

릴리즈 성격: 패치 릴리즈

## 변경점

- 터미널에서 한글 등 CJK 문자를 IME로 조합할 때 커서 블럭과 글자가 겹쳐 보이던 문제를 수정했습니다.
  - 조합 뷰(IME composition view) 배경을 활성 테마에서 파생한 **불투명** 색으로 바꿔, 그 아래 항상 그려지는 블럭 커서가 비쳐 겹쳐 보이지 않도록 했습니다. (업스트림 xterm.js / VS Code 기본 동작과 동일)
  - 기존에는 조합 뷰 배경을 18% 반투명으로 커스터마이징한 탓에 블럭 커서가 박스를 통해 비쳤습니다.
- 스택을 동일 메이저 내 최신 stable로 업데이트했습니다.
  - npm: `@tauri-apps/api` 2.11.1, `@tauri-apps/cli` 2.11.3, `svelte` 5.56.4(5.55.7 XSS 보안 패치 포함), `@sveltejs/vite-plugin-svelte` 7.1.2, `vite` 8.1.0, `typescript` 6.0.3
  - Rust: `tauri` 2.11.3, `tokio` 1.52.3 (`wry` 0.55.1 / `tao` 0.35.3 등 동반 갱신)
- 벤더링된 `portable-pty`를 0.8.1 → 0.9.0으로 올렸습니다.
  - 순정 0.9.0으로 교체한 뒤, ConPTY가 띄우는 콘솔 창을 숨기는 로컬 패치(`STARTF_USESHOWWINDOW` / `SW_HIDE`)를 재적용했습니다.
  - 0.8.1에만 있던 `cargo-clippy` 피처 셰임은 0.9.0에서 불필요해져 제거했습니다.

## 검증

- `cargo check -p portable-pty --manifest-path src-tauri/Cargo.toml`
